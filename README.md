# 🎬 CineMatch AI — Movie Recommendation System

A hybrid movie recommendation web application built with Python, Pandas, Scikit-learn, and Streamlit.

## 🚀 Features
- **Hybrid Recommendation Engine:** Combines Content-Based Filtering (Genre TF-IDF) and Collaborative Filtering.
- **Modern UI:** Dynamic Streamlit dashboard with real-time score weighting.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Streamlit
